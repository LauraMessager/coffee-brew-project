# About this project

The specialty coffee scene has grown rapidly, attracting coffee enthusiasts eager to deepen their understanding and refine their skills while supporting a more ethical and eco-friendly industry. The "third wave coffee" movement emphasizes sustainability, conscious sourcing, and a focus on quality over quantity, offering coffee drinkers a more meaningful experience.

This platform is designed to provide users with an engaging and user-friendly space to explore, create, and personalize coffee recipes. Whether you're interested in recreating award-winning recipes from coffee competitions or experimenting with different brewing methods at home, this platform offers a variety of tools to help you achieve the perfect cup. Users can access a library of diverse recipes, adjust ratios and brewing times to their preferences, and save or share their creations with a community of fellow coffee lovers.

Additionally, the platform includes a handy ratio calculator to help users convert measurements accurately, making it easier to experiment with different techniques. Regular updates will reflect the latest trends and innovations in the world of coffee, ensuring that the community stays connected to the cutting edge of the coffee scene.

For admins, the platform offers a robust back-office system to manage and update content, ensuring a seamless and evolving experience for users. Ultimately, this project aims to create a space that encourages a deeper connection to coffee, fostering a mindful and responsible approach to enjoying this beloved beverage.

# For developers

To install the project localy, the dev can clone the repo git.
Then in the _backend_ folder ruun the `symfony serve`command and in _frontend_ folder run the `npm run dev`command in order to starting working on the project localy.
Note that developers should create a new branch in order to keep clean oraginsation in the project.
